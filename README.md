# Retail Data Platform & AI

## Overview

A production-oriented data platform built around retail transaction data.
The project demonstrates data engineering, data quality, analytics,
machine learning, and AI capabilities using a realistic retail dataset.

## Current Status

### Phase 1 — Source Data Understanding
- Set up project structure
- Configured Python virtual environment
- Loaded Online Retail II dataset
- Inspected schema and data types
- Investigated relationships between StockCode and Description

### Technology
- Python
- Pandas
- Git/GitHub

## Data Source

UCI Online Retail II dataset.
